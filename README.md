# Cuezy ポン出し 説明書

12パッド × 5ページ（計60音源）のポン出しアプリです。
一度ホーム画面に追加すれば、**圏外・機内モードでも使えます**（インストール不要の Web アプリ / PWA）。

- iPhone（Safari）・Android（Chrome）・PC / iPad のブラウザで動作
- 画面サイズに合わせて自動で1画面にフィット（縦：3列×4段 / 横：6列×2段）
- 音源・設定は**端末の中だけ**に保存されます（サーバーには送信されません）

---

## 1. GitHub に公開する（最初に1回だけ）

1. GitHub にログインし、右上の「＋」→ **New repository** を押す
2. Repository name に好きな名前（例：`cuezy`）を入力し、**Public** を選んで **Create repository**
   - 無料プランで GitHub Pages を使うには Public が必要です
3. 作成後の画面で **uploading an existing file** を押す
4. この ZIP を解凍し、**中身のファイルとフォルダをすべて**ドラッグ＆ドロップする
   - `index.html` / `sw.js` / `manifest.webmanifest` / `README.md` / `icons` フォルダ / `libs` フォルダ / `.nojekyll`
   - フォルダごとアップロードできない場合は、PC のブラウザで行うか、GitHub Desktop を使ってください
   - `index.html` がリポジトリの一番上の階層（ルート）に来るようにします
5. 下の **Commit changes** を押す
6. リポジトリの **Settings → Pages** を開く
7. **Build and deployment** の Source を **Deploy from a branch** にし、Branch を **main / (root)** にして **Save**
8. 1〜2分待つと、画面上部に公開URLが表示されます

```
https://（あなたのユーザー名）.github.io/（リポジトリ名）/
```

このURLがアプリの入口です。

---

## 2. ホーム画面に追加する

### iPhone / iPad（Safari）
1. **Safari** で公開URLを開く（Chrome など他のブラウザではなく Safari）
2. 画面下の共有ボタン（□に↑）をタップ
3. **「ホーム画面に追加」** をタップ → 名前を確認して **追加**
4. ホーム画面の「Cuezy」アイコンから起動します

### Android（Chrome）
1. Chrome で公開URLを開く
2. 右上のメニュー（︙）→ **「ホーム画面に追加」** または **「アプリをインストール」**

### PC（Chrome / Edge）
アドレスバー右側の「インストール」アイコンを押します。

---

## 3. オフラインで使えるようにする

1. **ネットにつながった状態で**、ホーム画面のアイコンから一度アプリを起動する（これでアプリ本体が端末に保存されます）
2. 機内モードにして、もう一度ホーム画面のアイコンから起動し、開けば準備完了です

> ⚠️ 本番の前に、必ず**機内モードで起動できるか**を確認してください。
> 音源も端末内に保存されるので、ネットがなくても鳴ります。

---

## 4. 画面の見かた

上部のコントロールバーと、その下の12個のパッドで構成されています。

| 部品 | 説明 |
|---|---|
| **▶ 本番モード / ✏️ 編集モード** | 押すたびに切り替え。本番モードでは設定項目が隠れ、誤操作を防ぎます |
| **🔓 ロック / 🔒 ロック中** | 押すたびに切り替え。ロック中はパッドを触っても反応しません |
| **1〜5** | ページ切り替え（ページごとに12パッド） |
| シーン名 | そのページの名前（編集モードで入力） |
| ONLINE / DB接続中... | アプリ内データベースの状態 |

## 5. 使い方

### 音源を登録する（編集モード）
1. **✏️ 編集モード** にする
2. 登録したいパッドの **「音源選択」** をタップし、音声ファイルを選ぶ
3. パッドにファイル名が表示されれば登録完了（枠が水色になります）
4. 登録を外すときは、パッドの **「×」** を押して確認ダイアログで承認

対応形式：ブラウザが再生できる音声（MP3 / WAV / AAC / M4A など）。
iPhone の「ファイル」アプリや iCloud Drive 内の音声を選べます。

### パッドごとの設定（編集モード）
- **In / Out**：フェードイン・フェードアウトの秒数（0〜5秒、0.5秒刻み）。初期値は In 0秒 / Out 1.0秒
- **通常 / ソロ / ルプ**
  - **通常**：他の音と重ねて再生できます
  - **ソロ**：押すと他に鳴っている音をすべて止めて、これだけ鳴らします
  - **ルプ**：もう一度押して止めるまで繰り返し再生します
- **メモ欄**（パッド上部の文字入力）：曲名・キューなどを自由に書けます。文字サイズはパッドごと、または上部の「極小／標準／中」で全体を変更できます

### 本番での操作
1. **▶ 本番モード** にして、ページを選ぶ
2. パッドをタップすると再生。**再生中にもう一度タップ**すると、Out の秒数でフェードアウトして止まります
3. 再生中のパッドは水色に光ります
4. 操作しない間は **🔒 ロック** を押しておくと、ポケットの中などでの誤タッチで鳴りません
   - ロック中は、鳴っていない他のパッドが薄く表示されます
   - **ロック中は再生中の音を止められません**。止めたいときは先にロックを解除してください
   - ロック中でも、ページ切り替え（1〜5）は押せます

## 6. バックアップと復元

機種変更や、アプリの入れ直しに備えて、定期的にバックアップを取ってください。

1. **✏️ 編集モード** にする
2. **書出** をタップ → `SoundPad_Backup.zip` が保存されます（音源と全設定が入っています）
3. 復元は **読込** をタップして ZIP を選びます
   - ⚠️ **今ある全データが上書き**されます
   - 完了後、アプリが自動で再読み込みされます

> iPhone でホーム画面から起動したアプリ内で書き出しがうまくいかないときは、Safari で公開URLを開いて書き出してください。

---

## 7. アプリを更新する

`index.html` などを差し替えて GitHub にアップロードしたら、**`sw.js` の中の `CACHE_VERSION` の数字を上げて**ください（例：`'v1'` → `'v2'`）。

```js
const CACHE_VERSION = 'v2';
```

数字を変えないと、端末が古いキャッシュを使い続けて更新が反映されません。
反映は「ネットにつながった状態でアプリを起動 → 一度完全に閉じて、もう一度起動」で行われます。

---

## 8. 注意事項

- **データは端末ごと・URLごとに別々**です。公開URL（ユーザー名やリポジトリ名）を変えると、保存済みの音源は引き継がれません。変更前にバックアップを取ってください
- iPhone の「Safari のウェブサイトデータを削除」や、ストレージ不足、アプリの削除をすると、音源も消えることがあります。**大事な本番の前後にはバックアップ**を
- iPhone の**消音（サイレント）スイッチがオン**だと音が出ない場合があります。本番前に確認してください
- 本番前に、音量・ブルートゥース接続・機内モードでの起動を一度テストしてください
- 初回起動時と更新時だけ、ネット接続が必要です

---

## 9. うまく動かないとき

| 症状 | 対処 |
|---|---|
| 音が出ない | 消音スイッチ・音量を確認。一度パッドをタップして音声を有効にする |
| 「解読不可」と表示される | その音源形式を端末が再生できません。MP3 / M4A / WAV で書き出し直してください |
| オフラインで開かない | ネットにつながる状態で一度起動してから、もう一度試してください |
| 更新が反映されない | `sw.js` の `CACHE_VERSION` を上げたか確認し、アプリを完全に終了して再起動 |
| パッドが反応しない | 🔒 ロック中になっていないか確認（赤いボタンなら押して解除） |
| 画面が崩れる | 端末を一度回転させるか、アプリを再起動 |
