# Cuezy ポン出し 説明書

12パッド × 5ページ（計60音源）のポン出しアプリです。
一度ホーム画面に追加すれば、**圏外・機内モードでも使えます**（インストール不要の Web アプリ / PWA）。

- iPhone（Safari）・Android（Chrome）・PC / iPad のブラウザで動作
- 画面サイズに合わせて自動で1画面にフィット（縦：3列×4段 / 横：6列×2段）
- 音源・設定は**端末の中だけ**に保存されます（サーバーには送信されません）

---

## 1. GitHub に公開する（最初に1回だけ）

1. GitHub にログインし、右上の「＋」→ **New repository** を押す
2. Repository name に好きな名前（例：`cuezy`）を入力し、**Public** を選んで **Create repository**
   - 無料プランで GitHub Pages を使うには Public が必要です
3. 作成後の画面で **uploading an existing file** を押す
4. この ZIP を解凍し、**中身のファイルとフォルダをすべて**ドラッグ＆ドロップする
   - `index.html` / `sw.js` / `manifest.webmanifest` / `README.md` / `icons` フォルダ / `libs` フォルダ / `.nojekyll`
   - フォルダごとアップロードできない場合は、PC のブラウザで行うか、GitHub Desktop を使ってください
   - `index.html` がリポジトリの一番上の階層（ルート）に来るようにします
5. 下の **Commit changes** を押す
6. リポジトリの **Settings → Pages** を開く
7. **Build and deployment** の Source を **Deploy from a branch** にし、Branch を **main / (root)** にして **Save**
8. 1〜2分待つと、画面上部に公開URLが表示されます

```
https://（あなたのユーザー名）.github.io/（リポジトリ名）/
```

このURLがアプリの入口です。

## 2. ホーム画面に追加する

### iPhone / iPad（Safari）
1. **Safari** で公開URLを開く（Chrome など他のブラウザではなく Safari）
2. 画面下の共有ボタン（□に↑）をタップ
3. **「ホーム画面に追加」** をタップ → 名前を確認して **追加**
4. ホーム画面の「Cuezy」アイコンから起動します

### Android（Chrome）
1. Chrome で公開URLを開く
2. 右上のメニュー（︙）→ **「ホーム画面に追加」** または **「アプリをインストール」**

### PC（Chrome / Edge）
アドレスバー右側の「インストール」アイコンを押します。

---

## 3. オフラインで使えるようにする

1. **ネットにつながった状態で**、ホーム画面のアイコンから一度アプリを起動する（これでアプリ本体が端末に保存されます）
2. 機内モードにして、もう一度ホーム画面のアイコンから起動し、開けば準備完了です

> ⚠️ 本番の前に、必ず**機内モードで起動できるか**を確認してください。
> 音源も端末内に保存されるので、ネットがなくても鳴ります。

## 4. 画面の見かた

上部のコントロールバーと、その下の12個のパッドで構成されています。

| 部品 | 説明 |
|---|---|
| **▶ 本番モード / ✏️ 編集モード** | 押すたびに切り替え。本番モードでは設定項目が隠れ、誤操作を防ぎます |
| **🔓 ロック / 🔒 ロック中** | 押すたびに切り替え。ロック中はパッドを触っても反応しません |
| **1〜5** | ページ切り替え（ページごとに12パッド） |
| シーン名 | そのページの名前（編集モードで入力） |
| ONLINE / DB接続中... | アプリ内データベースの状態 |

## 5. 使い方

### 音源を登録する（編集モード）
1. **✏️ 編集モード** にする
2. 登録したいパッドの **「音源選択」** をタップし、音声ファイルを選ぶ
3. パッドにファイル名が表示されれば登録完了（枠が水色になります）
4. 登録を外すときは、パッドの **「×」** を押して確認ダイアログで承認

対応形式：ブラウザが再生できる音声（MP3 / WAV / AAC / M4A など）。
iPhone の「ファイル」アプリや iCloud Drive 内の音声を選べます。

### パッドごとの設定（編集モード）
- **In / Out**：フェードイン・フェードアウトの秒数（0〜5秒、0.5秒刻み）。初期値は In 0秒 / Out 1.0秒
- **通常 / ソロ / ルプ**
  - **通常**：他の音と重ねて再生できます
  - **ソロ**：押すと他に鳴っている音をすべて止めて、これだけ鳴らします
  - **ルプ**：もう一度押して止めるまで繰り返し再生します
- **メモ欄**（パッド上部の文字入力）：曲名・キューなどを自由に書けます。文字サイズはパッドごと、または上部の「極小／標準／中」で全体を変更できます

### 本番での操作
1. **▶ 本番モード** にして、ページを選ぶ
2. パッドをタップすると再生。**再生中にもう一度タップ**すると、Out の秒数でフェードアウトして止まります
3. 再生中のパッドは水色に光ります
4. 操作しない間は **🔒 ロック** を押しておくと、ポケットの中などでの誤タッチで鳴りません
   - ロック中は、鳴っていない他のパッドが薄く表示されます
   - **ロック中は再生中の音を止められません**。止めたいときは先にロックを解除してください
   - ロック中でも、ページ切り替え（1〜5）は押せます

## 6. バックアップと復元

機種変更や、アプリの入れ直しに備えて、定期的にバックアップを取ってください。
**音源が多い・大きいときは、ページごとに分けて取る**のがおすすめです（理由は下の「大きなデータのときは」を参照）。

### 書き出し
1. **✏️ 編集モード** にする
2. 書出ボタンの左にある選択欄で、書き出す範囲を選ぶ
   - **全ページ**：5ページ分すべて
   - **ページ1〜ページ5**：選んだページだけ
3. **書出** をタップ → 画面上部に進捗が表示されます
4. 「バックアップ完成」と出たら、その下の **「💾 保存 / 共有」** をタップ
   - iPhone では共有メニューが開くので、**「"ファイル"に保存」** などを選びます
   - PC などでは ZIP としてダウンロードされます
   - ファイル名は、全ページなら `Cuezy_Backup_年月日-時分.zip`、ページ別なら `Cuezy_Backup_Page2_年月日-時分.zip` のようになります
5. ZIP には、使っている音源と設定（メモ・モード・フェード・ページ名・文字サイズ）が入ります

### 復元
1. **✏️ 編集モード** にする
2. **読込** をタップして、バックアップの ZIP を選ぶ
3. 確認ダイアログが出るので、内容を確認して **OK** を押す
   - **全ページのバックアップ**：今ある音源と設定が**すべて**置き換わります（バックアップに無い設定は消えます）
   - **ページ別のバックアップ**：そのページ**だけ**が置き換わります。**他のページは変わりません**
4. 完了後に、アプリが自動で再読み込みされます

- ページ別のバックアップは、**書き出したときと同じページ番号に**戻ります（ページ2のバックアップはページ2に入ります）
- 復元の途中で失敗した場合（壊れたZIP、容量不足など）は、**今のデータは変更されません**。赤いエラーメッセージが表示されます
- 確認ダイアログでキャンセルしたときも、何も変わりません
- 以前のバージョンで作ったバックアップ（`SoundPad_Backup.zip`）も読み込めます（全ページ扱いになります）
- 読み込めるのは Cuezy のバックアップ ZIP だけです

### ZIPを解凍して、音源を手で選び直す（読み込みが重いときの最終手段）
1. ZIPを解凍する（iPhone は「ファイル」アプリでZIPをタップすると解凍されます）
2. 解凍したフォルダの `sounds` の中に音源が入っています
   - 新しい版で書き出したZIP：`P1-03_曲名.mp3` のように、**ページ1・パッド3の音源**だと分かる名前です
   - 以前の版で書き出したZIP：`sha_英数字…` という名前のファイルです（拡張子なし）。どのパッドの音源かは、同じ場所の `config.json` に書かれています
3. アプリを **✏️ 編集モード** にして、パッドの **「音源選択」** から、そのファイルを選ぶ
   - ファイルの種類の制限はないので、拡張子のないファイルも選べます
   - 以前の版のファイル名（`sha_…`）は、`音源_xxxxxx` のような短い名前で表示されます。曲名に直したいときは、選び直した後にパッドのメモ欄で書き換えてください
4. 設定（メモ・モード・フェードなど）は、この方法では戻りません。音源だけが戻ります

### 大きなデータのときは
- 読み込み中は、ZIPが**一時的に端末のメモリに載ります**（中の音源は1つずつ保存するので、ZIPのサイズ＋音源1つ分ほどです）。それでも数百MBになると、古い機種（iPhone SE など）では止まったり、アプリが落ちたりすることがあります
- 「ZIPファイルを解析中」から5分以上進まないときは、止まっています。アプリを完全に終了して開き直してください（今のデータは変わっていません）
- 対策：**ページごとに分けて書き出す／読み込む**、他のアプリをすべて終了してから行う、音源を MP3 / AAC などの軽い形式にする
- 再生時のメモリ節約の仕組みは、下の「長い曲とメモリ」を参照してください

> 💡 iPhone のホーム画面から起動したアプリ内で保存がうまくいかないときは、Safari で公開URLを開いて書き出してください。

## 6-2. 長い曲とメモリ（自動で切り替わります）

音源は登録したときの長さで、再生方式が自動で決まります。

| 長さ | 方式 | 特徴 |
|---|---|---|
| 30秒以下 | **メモリに展開して再生** | 押した瞬間に鳴る。ループもつなぎ目なし |
| 30秒より長い | **ストリーミング再生**（パッドの番号の横に「≋」が付く） | メモリをほとんど使わない |

- 3分のステレオ曲を12曲、1ページに入れた場合（PCのChromeでの測定）、アプリが使うメモリは旧版の約760MBから約130MBに減りました（MP3 128kbpsの場合。目安です）
- **表示しているページ以外の音源は、鳴っていなければ自動でメモリから外れます**。そのページに戻ると、自動で読み込み直します（進捗が表示されます）
- 再生中の音源は、ほかのページに移っても外れず、鳴り続けます
- ストリーミング再生の曲は、機種や音源の形式によって、**押してから鳴るまで少し遅れたり、ループのつなぎ目に一瞬の隙間が出たり**することがあります。ジングルや効果音など、瞬時に鳴らしたい音は、30秒以下にしてください
- iPhone では、ストリーミング再生中にロック画面へ再生コントロールが表示されることがあります
- 本番の前に、**長い曲を2曲同時に鳴らす／フェードする／ループする**のを、実際の端末で一度確認してください

## 7. アプリを更新する

`index.html` などを差し替えて GitHub にアップロードしたら、**`sw.js` の中の `CACHE_VERSION` の数字を上げて**ください（例：`'v7'` → `'v8'`）。

```js
const CACHE_VERSION = 'v8';
```

数字を変えないと、端末が古いキャッシュを使い続けて更新が反映されません。
反映は「ネットにつながった状態でアプリを起動 → 一度完全に閉じて、もう一度起動」で行われます。

---

## 8. 注意事項

- **データは端末ごと・URLごとに別々**です。公開URL（ユーザー名やリポジトリ名）を変えると、保存済みの音源は引き継がれません。変更前にバックアップを取ってください
- iPhone の「Safari のウェブサイトデータを削除」や、ストレージ不足、アプリの削除をすると、音源も消えることがあります。**大事な本番の前後にはバックアップ**を
- iPhone の**消音（サイレント）スイッチがオン**だと音が出ない場合があります。本番前に確認してください
- 本番前に、音量・ブルートゥース接続・機内モードでの起動を一度テストしてください
- 初回起動時と更新時だけ、ネット接続が必要です

## 9. うまく動かないとき

| 症状 | 対処 |
|---|---|
| 音が出ない | 消音スイッチ・音量を確認。一度パッドをタップして音声を有効にする |
| 復元しようとして「バックアップファイルではありません」と出る | Cuezy の書出で作った ZIP を選んでください（解凍したり、中身を作り替えたりしていない ZIP） |
| 「解読不可」と表示される | その音源形式を端末が再生できません。MP3 / M4A / WAV で書き出し直してください |
| オフラインで開かない | ネットにつながる状態で一度起動してから、もう一度試してください |
| 更新が反映されない | `sw.js` の `CACHE_VERSION` を上げたか確認し、アプリを完全に終了して再起動 |
| パッドが反応しない | 🔒 ロック中になっていないか確認（赤いボタンなら押して解除） |
| 長い曲だけ、押してから鳴るまで遅い・ループに隙間がある | 30秒より長い音源はストリーミング再生のためです（6-2参照）。瞬時に鳴らしたい音は30秒以下にしてください |
| 画面が崩れる | 端末を一度回転させるか、アプリを再起動 |
